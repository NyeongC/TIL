# 스프링 AI

## 스프링 AI란

Spring 애플리케이션에서 AI 기능을 쉽게 사용할 수 있도록 지원하는 프레임워크

기존에는 OpenAI, Google, Anthropic 등 공급자마다 다른 API와 SDK를 사용해야 했지만,

Spring AI는 이를 공통 인터페이스로 추상화하여 일관된 방식으로 사용할 수 있게 해준다.

### 제공 기능

* Spring 스타일 API 제공
* 프롬프트 관리
* 구조화된 출력
* 임베딩 및 RAG 지원
* 대화 기록(Memory) 관리
* Tool Calling 지원
* 스트리밍 응답 지원

---

## AI 애플리케이션이란?

AI 모델을 활용하여 사용자에게 지능적인 기능을 제공하는 소프트웨어

예시

* ChatGPT
* AI 챗봇
* 이미지 생성 서비스
* 문서 요약 서비스
* 번역 서비스

### Spring AI 등장 배경

기존에는 OpenAI, Google, Anthropic 등 공급자별 API를 직접 관리해야 했다.

문제점

1. 공급자마다 API 명세가 달라 복잡도 증가
2. 특정 공급자에 종속됨
3. 프롬프트, 대화 이력, 컨텍스트 관리를 직접 구현해야 함

이러한 문제를 해결하기 위해 Spring AI가 등장했다.

## AI 모델이란?

인간의 인지 기능을 모방하여 정보를 처리하거나 생성하도록 설계된 알고리즘

### 모델 종류

* LLM (텍스트 생성)
* 이미지 생성 모델
* 임베딩 모델
* TTS(Text To Speech)
* STT(Speech To Text)

※ AI 모델 = LLM 이 아님

LLM은 AI 모델의 한 종류이다.

---

## 토큰(Token)이란?

LLM이 텍스트를 처리하는 최소 단위

모델은 문장을 통째로 이해하지 않고 토큰 단위로 분리하여 처리한다.

예시

```text
안녕하세요.

↓

안녕
하세요
.
```

### 특징

* 입력도 토큰
* 응답도 토큰
* 모델은 토큰을 하나씩 생성하며 답변 생성

※ 토큰 1개 ≒ 영단어 0.75개 정도

### 개발자가 토큰을 알아야 하는 이유

#### 비용 절감

대부분의 AI 서비스는

```text
입력 토큰 + 출력 토큰
```

기준으로 과금한다.

#### 컨텍스트 윈도우 제한

모델마다 처리 가능한 최대 토큰 수가 존재한다.

이를 초과하면 오류가 발생하거나 이전 대화가 잘릴 수 있다.

---

## 프롬프트(Prompt)란?

AI 모델에게 작업을 수행하도록 지시하는 명령어 또는 입력 텍스트

예시

```text
Spring AI에 대해 설명해줘
```

프롬프트 품질에 따라 응답 품질도 달라진다.

---

## 구조화된 출력(Structured Output)

LLM의 응답을 단순 문자열이 아닌 객체 형태로 받는 방식

예시

```json
{
  "name": "홍길동",
  "age": 30
}
```

Spring AI는 이를 DTO, Record 등 Java 객체로 바로 변환할 수 있다.

장점

* JSON 파싱 코드 감소
* 타입 안정성 확보
* 응답 처리 편의성 증가

---

## 벡터(Vector)와 임베딩(Embedding)

### 임베딩

텍스트를 숫자 벡터로 변환하는 과정

예시

```text
고양이

↓

[0.12, -0.53, 0.89, ...]
```

### 벡터 공간

임베딩된 벡터들이 저장되는 공간

의미가 비슷한 문장일수록 가까운 위치에 저장된다.

### 활용

* 유사도 검색
* 문서 검색
* 추천 시스템
* RAG

---

## AI 모델의 Knowledge Cutoff

LLM은 학습 시점 이후의 정보를 알지 못한다.

예시

```text
GPT-3.5

Knowledge Cutoff
2021년 9월
```

따라서 이후 발생한 사건이나 데이터는 알 수 없다.

### 해결 방법

* RAG
* Tool Calling
* 웹 검색
* 최신 데이터 연동

※ 파인튜닝은 모델의 행동이나 특정 도메인 학습에는 도움되지만 최신 정보 제공을 위한 대표적인 해결책은 아니다.
