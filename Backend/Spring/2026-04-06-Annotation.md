# 어노테이션 (Annotation)

## 한줄 정의

👉  
코드에 추가 정보를 제공하여, 컴파일러나 런타임에 특정 동작을 하도록 하는 메타데이터

---

## 📌 쉽게 말하면

👉  
코드에 붙이는 설정값/표시

---

## 📌 예시

```java
@Override
public String toString() {
    return "hello";
}
```

👉  
“이 메서드는 부모 메서드 오버라이드임”을 알려줌

---

## 📌 왜 쓰냐?

### 1️⃣ 코드 동작 제어
- @Transactional → 트랜잭션 처리
- @GetMapping → HTTP 요청 매핑

---

### 2️⃣ 컴파일 체크
- @Override → 오버라이드 확인

---

### 3️⃣ 자동 처리 (Spring 핵심 ⭐)
- @Component → 빈 등록
- @Autowired → 의존성 주입

---

## 📌 핵심 특징

👉 실제 로직이 아니라 “정보”를 제공하는 것

- 코드 실행 X
- 대신 프레임워크가 해석해서 동작함

---

## 📌 한줄 정리

👉  
어노테이션은 코드에 의미를 부여하고, 이를 기반으로 특정 동작을 수행하도록 하는 메타데이터이다

---

## 🔥 실무 감각 한줄

👉  
Spring은 어노테이션을 읽어서 빈 등록, DI, 트랜잭션 등을 자동으로 처리한다
