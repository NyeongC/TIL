### CORS (Cross-Origin Resource Sharing)

---

다른 출처(origin)에서 오는 API 요청을 브라우저가 제한하는 정책

---

### 예시 상황

프론트: http://localhost:3000  
백엔드: http://localhost:8080  

→ Origin 다름 (포트도 포함됨)  
→ 브라우저가 요청 차단

---

### 문제 코드

```javascript
fetch("http://localhost:8080/api")
```

→ 브라우저에서 CORS 에러 발생

---

### 해결 코드

```java
@CrossOrigin(origins = "http://localhost:3000")
@RestController
public class ApiController {}
```

또는

```java
http.cors();
```

---

### 핵심

브라우저가 막는 것  
서버 문제가 아님  
Postman에서는 발생 안함

---

### CSRF (Cross-Site Request Forgery)

---

로그인된 사용자의 권한을 이용해 의도하지 않은 요청을 보내는 공격

---

### 예시 상황

1. 내가 은행 사이트 로그인 상태
2. 악성 사이트 접속

```html
<form action="https://bank.com/transfer" method="POST">
  <input type="hidden" name="money" value="1000000">
</form>
<script>document.forms[0].submit()</script>
```

→ 자동 요청 발생  
→ 서버는 정상 요청으로 인식 (쿠키 포함됨)

---

### 해결 방법

CSRF 토큰 사용

```html
<input type="hidden" name="_csrf" value="랜덤값">
```

---

### Spring Security 설정

```java
http.csrf().disable(); // JWT 사용 시 보통 비활성화
```

---

### 핵심

쿠키 기반 인증에서 발생  
Session 방식에서 중요  
JWT는 영향 거의 없음

---

### 정리

CORS = 다른 출처 요청 제한 (브라우저)  
CSRF = 로그인 상태 악용 공격 (서버 보안)
