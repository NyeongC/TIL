# 🚀 Today I Learned (TIL)

> 매일 작은 학습을 기록하며 꾸준히 성장하기 위한 저장소

---

## 💡 Purpose
- 매일 배운 내용을 기록으로 남긴다
- 완벽한 정리보다 **지속적인 기록**에 집중한다
- 작은 지식도 쌓이면 큰 자산이 된다

---

## 📌 Rule

### 1. Daily TIL
- 학습한 내용을 **주제별로 분리하여 기록**
- 파일명 규칙  
  → yyyy-mm-dd-topic.md

예시:
Spring/2026-03-31-di.md
Redis/2026-03-31-rate-limit.md

---

### 2. One Topic One File
- 하나의 파일에는 하나의 주제만 작성
- 여러 개 배웠다면 파일을 나눠서 기록

---

### 3. Accumulation → Consolidation
- 일정 수준 이상 쌓이면 하나의 문서로 통합

예시:
Spring/
├── 2026-03-31-di.md
├── 2026-04-01-di-example.md
├── DI.md   ← 통합 정리

- 통합 문서는 핵심 개념 + 실무 적용 중심으로 정리

---

### 4. Commit Convention
- 커밋 메시지는 학습 내용을 기준으로 작성
- `docs:` prefix를 사용하여 문서 변경임을 명시

예시:

docs: DI 개념 정리  
docs: Redis rate limit 구조 정리  

여러 주제를 함께 커밋하는 경우:

git commit -m "docs: DI, JWT 개념 정리"

---

### 5. Directory Rule
- 디렉토리 및 파일명은 영어로 작성
- 기술 스택 기준으로 분류
