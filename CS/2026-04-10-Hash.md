# 해시 알고리즘

## 정의
해시 알고리즘은 임의의 길이의 데이터를 입력받아  
고정된 길이의 해시값으로 변환하는 단방향 함수이다.

---

## 특징
- 단방향 (원본 복구 불가)
- 출력 길이는 항상 고정
- 입력값이 조금만 바뀌어도 결과는 완전히 달라짐

---

## 실무에서 사용

### 1. 비밀번호 저장
- DB에 평문 저장하지 않고 해시값 저장
- 로그인 시 입력값을 해시해서 비교

```java
passwordEncoder.encode("1234");
passwordEncoder.matches(raw, encoded);
```

---

### 2. HashMap
- key를 해시값으로 변환해서 저장 위치 결정
- 평균 O(1) 조회 성능

---

### 3. 캐시 / 중복 방지
- Redis key
- 요청 중복 처리
- 파일 중복 체크

---

### 4. 데이터 무결성 검증
- 파일 전송 전/후 해시값 비교
- 데이터 변조 여부 확인

---

## 실무 포인트
- SHA256 같은 빠른 해시는 비밀번호 용도로 부적합
- BCrypt, Argon2 같은 느린 해시 사용
- salt 포함해서 보안 강화

---

## 해시 vs 암호화
- 해시: 복호화 불가, 비교 목적
- 암호화: 복호화 가능, 데이터 보호 목적

---

## 한줄 정리
해시는 데이터를 비교하기 위한 '지문' 역할을 한다.
