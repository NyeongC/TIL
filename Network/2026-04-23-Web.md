## 웹(Web)

> 웹이란 인터넷 위에서 HTTP 프로토콜을 통해 리소스를 주고받는 정보 시스템이다.

---

### 핵심 구성

* 인터넷 위에서 동작
* HTTP 프로토콜 사용
* 리소스(Resource)를 주고받음
---

### 리소스란?

웹에서 주고받는 대상

HTML (웹 페이지)
JSON (API 응답)
이미지 / 파일
---

### 동작 구조
```
클라이언트(브라우저) → 서버 요청
서버 → HTTP 응답 반환
```
---

### 핵심 포인트

* 인터넷 ≠ 웹 **(인터넷은 물리적으로 연결된 전세계의 네트워크 망 자체)**
* 웹은 인터넷 위에서 동작하는 서비스 중 하나
* HTTP는 웹 통신 규칙
---

### 한 줄 정리

> 웹 = 인터넷 + HTTP + 리소스 교환 시스템
