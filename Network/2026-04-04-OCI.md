# 📌 OCI 서버 접속 삽질 정리 (실전 흐름)

---

## 📖 한줄 요약

👉  
OCI는 **네트워크 → 보안 → OS 방화벽** 3단계 모두 열려야 외부 접속 가능

---

## 📌 실제 삽질 흐름 (중요 ⭐)

### 1️⃣ 인스턴스 생성 + Ubuntu 설치

- 공인 IP 생성
- 서버 정상 실행

👉 하지만 접속 안됨 ❌

---

### 2️⃣ 보안 설정 확인

- 포트 허용 (8080, 22)
- Security List / NSG 설정

👉 그래도 안됨 ❌

---

### 3️⃣ 인터넷 게이트웨이 문제

👉 원인

- IGW 없음 or 연결 안됨

👉 해결

- Internet Gateway 생성
- 라우팅 테이블 연결

```text
0.0.0.0/0 → Internet Gateway
```

👉 다시 테스트 → 여전히 안됨 ❌

---

### 4️⃣ 서브넷 문제

👉 퍼블릭 서브넷 설정 필요

- 공인 IP 연결
- 외부 통신 가능해야 함

👉 수정 후 → 또 안됨 ❌

---

### 5️⃣ 최종 원인 (진짜 핵심🔥)

👉 OS 방화벽 (iptables)

---

## 📌 해결 방법

```bash
sudo iptables -I INPUT 1 -p tcp --dport 8080 -j ACCEPT
```

👉 적용 후

👉 바로 접속 성공 ⭕

---

## 📌 전체 구조 이해

```text
인터넷
   ↓
OCI 네트워크 (VCN, 서브넷, IGW)
   ↓
보안 설정 (NSG / Security List)
   ↓
서버 OS 방화벽 (iptables) ⭐
   ↓
애플리케이션 (8080)
```

---

## 📌 체크 순서 (실무용 ⭐)

1️⃣ 공인 IP 확인  
2️⃣ IGW + 라우팅 확인  
3️⃣ 서브넷 퍼블릭 여부  
4️⃣ 포트 허용 (NSG / Security List)  
5️⃣ 서버 실행 여부  
6️⃣ iptables 확인  

---

## 📌 핵심 깨달음

👉  
클라우드는 한 군데만 열어도 안됨

👉  
**네트워크 / 보안 / OS 방화벽 3단계 모두 통과해야 한다**

---

## 📌 한줄 정리

👉  
OCI에서 접속이 안되면 네트워크 설정보다도 마지막 단계인 OS 방화벽(iptable)을 반드시 확인해야 한다
